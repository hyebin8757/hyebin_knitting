# 🚨 포트폴리오 UX/UI 크리티컬 리뷰 (팩트 폭격 리포트)

전체적인 컨셉(IDE 클론)과 기술력은 매우 훌륭하지만, **시인성(접근성)과 디테일한 레이아웃 부분에서 치명적인 UX/UI 결함들**이 다수 발견되었습니다. 특히 '라이트 모드'와 '모바일 환경'에서 사용성을 크게 해치는 요소들이 있어 시급한 개선이 필요합니다.

---

## 1. 심각한 시인성 및 대비(Contrast) 문제
**가장 시급하게 수정해야 할 부분입니다. 라이트 모드에서의 색상 대비율이 완전히 무너져 있습니다.**

*   **보이지 않는 텍스트 (`contact.css`)**: 라이트 모드일 때 이메일, GitHub, 카카오톡 텍스트가 밝은 크림색 배경 위에 '매우 밝은 하늘색'으로 표시되어 거의 **투명 클로킹 수준으로 안 보입니다.** (사용자가 연락처를 읽을 수가 없습니다)
*   **태그 및 콘솔 가독성 최악 (`about.html`)**: 라이트 모드에서 `UI 개발`, `프론트 개발` 같은 태그 하이라이팅 색상(노란색, 밝은 오렌지색)과, 콘솔 로그의 연두색/노란색 텍스트가 밝은 배경에 완전히 묻혀버려 시인성이 0에 가깝습니다. 눈이 매우 피로해집니다.
*   **사이드바 탭 대비**: 활성화된 사이드바 탭(`project.js` 등)의 배경이 밝은 노란색/오렌지색인데, 그 위의 글씨가 '흰색'입니다. WCAG 웹 접근성 대비율 기준을 완전히 통과하지 못하는 수준입니다. 활성화 탭 글씨는 어두운 색으로 바꿔야 합니다.
*   **다크 모드 경고문**: 다크 모드일 때 프로젝트 리스트 우측 상단에 있는 `* 보안상 문제가 발생할 수 있어 링크를 연결하지 않았습니다.` 라는 붉은색 경고 텍스트가 짙은 남색 배경에 묻혀서 전혀 눈에 띄지 않습니다.

## 2. 레이아웃 겹침 및 잘림 현상 (Clipping/Bleeding)
*   **프로젝트 탭 전환 시 화면 깨짐 (`project.js`)**: `MAINPROJECT.TS`에서는 정상적이지만, `NEWPROJECT.JSON`이나 `RENEWALPROJECT.LOCK` 탭을 클릭하면 컨테이너 범위(Overflow) 계산에 오류가 생깁니다. **첫 번째 카드 이미지가 왼쪽으로 삐져나가 잘리거나, 옆 탭에 있던 카드 이미지(예: 리마커블소프트 보라색 카드)가 잔상처럼 겹쳐 보이는 현상**이 발생합니다.

## 3. 모바일 환경의 치명적 결함 (Unusable on Mobile)
*   **스크롤 불가 현상**: 화면 너비가 모바일 사이즈(또는 태블릿 세로 모드)로 작아질 경우, **세로 스크롤 자체가 완전히 먹통**이 됩니다. 즉, 접힌 화면(Fold) 아래에 있는 다른 프로젝트 카드들은 영원히 볼 수가 없는 상태입니다. 모바일 대응이 완전히 깨져있습니다.
*   **햄버거 메뉴 오작동**: 모바일에서 햄버거 메뉴 아이콘을 누르면 네비게이션 서랍(Drawer)이 슬라이드되어 나오긴 하지만, 화면 왼쪽 끝에 반쯤 걸쳐진 채로 나와서 메뉴 글씨를 제대로 읽거나 클릭하기가 매우 어렵습니다.

## 4. 치명적인 기능(Link) 버그
*   **이메일 오타 (`contact.css`)**: 화면에 보이는 글씨는 `dnwkeke2@gmail.com`인데, 실제 HTML의 `href="mailto:..."` 에는 `dnwnekek2@gmail.com`으로 **'n'과 'e'가 실수로 더 들어가 있습니다.** 포트폴리오를 본 면접관이 클릭해서 메일을 보내면 전송 실패가 뜹니다.
*   **GitHub 링크 미작동**: 이메일과 카카오톡은 클릭이 되는 a태그 링크로 구현되어 있는데, GitHub 핸들(`miuju`)은 클릭이 안 되는 단순 텍스트로 방치되어 있습니다.

### 💡 총평 및 권고사항
"개발자다운 화려한 컨셉과 기술력에 집중하느라, 정작 사용자가 사이트를 '편하게 읽고 탐색하는' **가장 기본적인 UI/UX 기본기를 많이 놓쳤다**"는 인상을 강하게 줍니다. 

특히 **1) 라이트 모드 색상 대비**, **2) 모바일 스크롤/메뉴 버그**, **3) 이메일 링크 오타** 이 세 가지는 포트폴리오의 치명타가 될 수 있으므로 코드를 반드시 수정하시길 권장합니다.
