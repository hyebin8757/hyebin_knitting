# 🧶 앉은누이 뜨개옷장 (혜빈이와 먼작콩 공방)

동글동글 귀여운 인형 친구들을 위한 사랑스러운 맞춤 뜨개옷 주문 및 관리 플랫폼입니다.  
구글 설문지(Google Forms) 기반의 주문서를 현대적이고 세련된 반응형 웹 쇼핑몰 형태로 개편 및 구축하였습니다.

---

## 🌟 주요 기능 및 페이지 안내

### 1. 구매자용 메인 페이지 (`/`)
- **히어로 배너**: 2026 앉은누이 뜨개옷 컬렉션 소개 및 빠른 주문/후기/문의 바로가기
- **공지사항 & 배송 안내 카드**:
  - `[공지사항]`: 100% 핸드메이드 특성 안내, 제작 기간(약 3~7일 소요), 단순 변심 교환/환불 정책
  - `[배송안내]`: 일반 택배(4,000원 / 제주 5,000원), GS25 반택 / CU 알뜰택배(2,000원)
  - `[세탁 시 주의사항]`: 미온수 중성세제 조물조물 손세탁 권장
- **9종 뜨개옷 카탈로그**:
  - 사과 (14,000원)
  - 사과 데빌 ver. (14,000원)
  - 복숭아 (14,000원)
  - 복숭아 세라(파랑, 분홍) ver. (15,000원)
  - 레몬 (14,000원)
  - 딸기 (14,000원)
  - 장미 산타 ver. (15,000원)
  - 장미 기본/보닛 ver. (15,000원)
  - 도토리 모자 세트 (15,000원)
  - 각 상품별 실물 고화질 크롭 이미지 및 설명 태그, 주문서 자동 담기 연동
- **구매자 솔직 후기 미리보기**: 별점 및 실구매 인증 후기 캐러셀
- **내 주문 실시간 조회 배너**: 전화번호 또는 주문번호로 배송 상태 즉시 조회

### 2. 구매자 구매 (주문서 작성) 페이지 (`/order`)
- 구글 폼 주문서의 모든 입력 양식을 세련된 UI로 구현:
  - 인스타그램 아이디 (`@...`)
  - 수령자 성함
  - 연락처 (휴대폰 번호)
  - 배송받으실 주소 (일반 주소 또는 반값택배 GS/CU 점포명)
  - 주문 제품 선택 (9종 그리드, 체크박스 및 `+/-` 수량 조절기, 소계 계산)
  - 배송 방식 선택 (일반택배 4,000 / 제주도서산간 5,000 / 편의점 반택 2,000)
  - 배송 시 요청사항 / 기타 메모
  - 입금 계좌 확인 및 원클릭 복사 (`카카오뱅크 3333-12-8924018 전혜빈`)
  - 실제 입금자명 입력란
  - 실시간 결제 금액 요약 (상품 금액 + 배송비 = 최종 결제액)
- 주문서 제출 시:
  - 고유 주문번호(`ORD-YYYYMMDD-XXXX`) 발급
  - 관리자 스마트폰 카카오톡 실시간 푸시 알림 자동 발송
  - 주문 상세 확인 및 배송 상태 조회 연결

### 3. 포토 리뷰 작성 및 열람 페이지 (`/reviews`)
- 평균 평점 통계 (5점 만점) 및 만족도 지표
- 별점 필터 (전체, 5점, 4점, 3점) 및 상품별 필터
- `+ 후기 작성하기` 모달:
  - 별점 1~5점 선택
  - 구매 상품 선택
  - 닉네임 / 인스타 ID
  - 리뷰 본문
  - 착용 사진 첨부 (파일 업로드 즉시 미리보기)
- 착용샷 이미지 클릭 시 전체 화면 확대 모달
- '도움돼요 (좋아요)' 버튼 및 구매 인증 배지

### 4. 전역 실시간 알림 센터 모달 (`NotificationModal`)
- **언제 어디서든 원클릭 오픈**:
  - 상단 헤더의 🔔 **벨 아이콘** (안 읽은 알림 배지 개수 표시 및 깜빡임)
  - 모바일 하단 네비게이션의 🔔 **알림 탭**
  - 관리자 대시보드 상단의 🔔 **알림 모달 버튼**
- **모바일 바텀 시트 (Bottom Sheet) 애니메이션**:
  - 모바일에서는 드래그 핸들이 달린 바텀 시트 형태로 아래에서 스르륵 부드럽게 올라옵니다.
- **카테고리별 실시간 알림 탭**:
  - `전체` / `🛍️ 주문` / `💸 환불` / `💌 문의` / `⭐ 후기`
  - 항목별 주문자, 결제 금액, 상품 구성, 주문번호 등 핵심 메타 정보 한눈에 확인
  - `[주문번호 복사]`, `[상세보기 / 상태변경]` 원클릭 빠른 액션 지원
  - [모두 읽음], [모두 비우기], 개별 알림 삭제 지원
- **알림 간편 제어 바**:
  - 소리(🔊/🔇) 및 진동(📳) ON/OFF 원클릭 토글
  - 카카오톡 연동 상태 표시 및 [🔔 알림 테스트] 즉시 발송

### 5. 전역 의견 & 문의 보내기 모달 (`FeedbackModal`)
- 사이트 상단 헤더, 하단 푸터, 모바일 하단바 어디서든 원클릭 오픈
- 문의 유형: `상품 문의`, `커스텀 제작 의뢰`, `배송/주문 문의`, `사이트 건의사항`, `기타 의견`
- 이름/닉네임, 연락처/인스타ID, 문의 내용 작성 후 제출
- 제출 즉시 관리자에게 모바일 알림 발송 및 관리자 대시보드에 접수

### 6. 관리자 로그인 페이지 (`/admin/login`)
- 관리자 전용 비밀번호 인증
- 기본 비밀번호: `admin1234` (관리자 설정에서 변경 가능)
- 원클릭 자동 로그인 데모 버튼 제공

### 7. 관리자 통합 대시보드 (`/admin`)
- **실시간 새 주문 감지기**: 상시 대기 상태로 주문 접수 시 알림음/진동 발생
- **KPI 통계 카드**: 전체 주문, 입금 대기, 제작 중, 배송 중, 환불 요청, 신규 문의
- **구매 (주문) 관리 탭**:
  - 상태별 필터 (입금대기, 입금확인, 제작중, 배송중, 배송완료, 취소)
  - 주문자명, 인스타ID, 연락처, 주문번호 실시간 검색
  - 배송지 주소 원클릭 복사
  - 운송장 번호 입력 및 배송 중 전환
  - 빠른 상태 변경: `입금 확인` → `제작 시작` → `배송 출발` → `배송 완료` → `주문 취소`
- **환불 / 취소 관리 탭**:
  - 고객의 환불 신청 내역 (주문번호, 사유, 금액)
  - 환불 계좌 정보 확인 및 원클릭 복사
  - `환불 완료 처리` 및 `반려 처리`
- **고객 의견 / 문의 관리 탭**:
  - 유형별(커스텀의뢰, 상품문의 등) 고객 접수 내역
  - 상태 변경 (`미확인` ↔ `답변/처리완료`)
  - 관리자 메모 및 답변 기록
- **리뷰 관리 탭**:
  - 고객 리뷰 노출/숨김 토글 및 삭제 관리
- **휴대폰 알림 & 상점 설정 탭**:
  - 스마트폰 소리 및 진동 알림 ON/OFF
  - 알림음 테스트 버튼 (크리스탈 4단 차임벨)
  - 브라우저 웹 알림(Web Push) 권한 요청
  - **카카오톡(KakaoTalk) 관리자 실시간 알림 연동**: '나에게 보내기' API, 토큰 설정 및 테스트 알림 발송
  - 주문 / 환불 / 리뷰 / 고객 문의 이벤트별 카카오톡 알림 개별 ON/OFF
  - 공식 입금 계좌 정보 변경 (은행, 계좌번호, 예금주)
  - 관리자 비밀번호 변경

## 🔔 관리자 카카오톡(KakaoTalk) 실시간 알림 시스템

관리자 본인의 스마트폰 카카오톡으로 **주문, 환불, 리뷰, 고객 문의** 발생 시 카톡 알림음과 함께 즉시 메시지가 도착합니다.

### 1. 발송 대상 이벤트 및 카톡 내용
1. **🛍️ 신규 주문 접수 시**:
   - `🔔 [새 뜨개옷 주문 도착!]`
   - 주문번호, 주문자명, 인스타 ID, 연락처, 주문상품 목록(수량), 총 결제금액, 배송지 주소, 입금자명, 요청사항
2. **💸 환불 / 취소 신청 시**:
   - `💸 [환불/취소 요청 접수!]`
   - 주문번호, 신청자, 환불금액, 환불사유, 환불 계좌(은행, 계좌번호, 예금주)
3. **⭐ 새 포토 리뷰 등록 시**:
   - `⭐ [새 포토 리뷰 등록!]`
   - 작성자명, 별점(★), 구매 상품명, 후기 내용
4. **💌 고객 문의 / 의견 접수 시**:
   - `💌 [새 고객 문의/의견 접수!]`
   - 문의 유형, 작성자명, 연락처, 문의 내용

### 2. 카카오톡 연동 방법 (100% 무료, 사업자 등록 불필요)
1. **관리자 페이지**(`/admin`) 접속 후 **[휴대폰 알림 & 상점 설정]** 탭 이동
2. [카카오 로그인으로 1초 연동] 또는 [카카오 디벨로퍼스 액세스 토큰] 입력
3. [💛 내 카톡으로 테스트 알림 보내기] 버튼을 눌러 스마트폰 카카오톡('나와의 채팅')으로 즉시 테스트 메시지 수신 확인!

## 🔔 휴대폰 소리 및 브라우저 알림 시스템

1. **맑은 크리스탈 차임 소리 & 진동 (Web Audio API)**
   - 스마트폰 모바일 브라우저 또는 PC에서 관리자 페이지 접속 시, 주문 접수 순간 고음질 4단 차임벨 소리와 진동(`navigator.vibrate`)이 울립니다.
2. **웹 브라우저 푸시 알림 (Web Notification API)**
   - 스마트폰 화면 상단에 배너 팝업으로 새 주문자명과 상품 구성이 표시됩니다.
